Pitman — это классическая игра-головоломка, изначально созданная в 1985 году для компьютеров Sharp MZ. Данная версия адаптирована для PicoCalc с разрешением 320×320, работающего на PicoMite MMBasic.
#История игры
Игра Pitman (в оригинале — Pitman) была создана Ютакой Исокавой (Yutaka Isokawa) в 1985 году на языке BASIC для компьютера Sharp MZ-700. В августе 1985 года листинг программы был опубликован в японском журнале Oh!MZ, посвященном линейке компьютеров Sharp.

Оригинальная версия была написана для HU-BASIC — специфической реализации BASIC для Sharp MZ. Позже Сильвен Бизуар (Sylvain Bizoirre) адаптировал код для S-BASIC — более распространенной версии языка. Адаптированная версия была опубликована в ноябрьском выпуске французского журнала Sharpentiers (No15, Novembre 1985).
